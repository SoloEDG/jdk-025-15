# 遗迹探勘

安装：`npm install`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:18225。

## 假设分支推断

除了旗标、疑问与清除，推断面板支持可命名、切换、删除的**假设分支**：

- 每个分支记录若干「某格是危险 / 安全」的假设。写假设不会揭开石板、不消耗道具、不收集文物，也不修改真实旗标。
- 分支只是假设，**不会**当成事实。地图上用虚线与角标单独显示当前分支的假设。
- 合并结论由求解器重新计算：它枚举所有符合公开数字的完整布局，并对所选分支的假设格做**完整情形拆分**（2ⁿ 个组合，而不只是你手动建的组合）。
  - 每个可行情形都必须被某个所选分支覆盖，否则合并不成立（显示未覆盖数）。
  - 矛盾、空、或未枚举完的分支不计入支持。
  - 只有每个可行情形都得到同一结论、且覆盖无遗漏时，合并才标记为「可提交」，其结论才用于安全探索。
  - 重复覆盖与遗漏都会在卡片中给出计数说明。
- 新数字出现后会立即重算覆盖与证明；未算完（超过枚举上限）只显示「待证」，绝不使用暗格答案。
- 重命名、切换、删除分支只改变假设本身，不改变已消耗的道具、生命与已获得的发现。

核心实现位于 `src/features/inference/lib/`：`constraints.ts`（公开线索）、`enumerate.ts`（联合布局与情形拆分）、`deduce.ts`（分支与合并证明）。

验证脚本（仅测试用，会对照隐藏答案检查合并结论，应用本身不读取答案）：

```
npx esbuild verify/check.ts --bundle --format=esm --platform=node --outfile=/tmp/check.mjs && node /tmp/check.mjs
```
